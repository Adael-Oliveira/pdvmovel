# PDVMovel (MVP)

Site e painéis do terminal de autoatendimento PDVMovel, publicados no GitHub Pages.

| Caminho | Quem usa |
|---|---|
| `/` | Site provisório do produto |
| `/cliente/` | Painel do estabelecimento — entra só o e-mail Google cadastrado pela plataforma |
| `/plataforma/` | Painel do administrador (adaeloliveira.ao@gmail.com): cadastra restaurantes, donos, suspende e dá suporte |

Dados no Firebase (projeto `pdvmovel-95afb`). As regras de segurança do Realtime Database estão em `firebase.rules.json`.
